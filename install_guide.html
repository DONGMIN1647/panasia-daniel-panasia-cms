QR코드 스캔 또는 URL을 직접 입력하여 Safari로 접속합니다.

홈 화면에 추가
공유 버튼 → 홈 화면에 추가
1️⃣
Safari 하단 가운데 공유 버튼 (□↑)을 탭합니다
2️⃣
스크롤을 내려 "홈 화면에 추가"를 탭합니다
3️⃣
앱 이름 확인 후 오른쪽 상단 "추가"를 탭합니다
✅
홈 화면에 PANASIA CMS 아이콘이 생성됩니다!

3️⃣
"설치" 버튼을 눌러 완료합니다
✅
홈 화면과 앱 서랍에 PANASIA CMS 아이콘이 생성됩니다!
